Workflow via browser:
1. Import .mxl / .xml langsung → generate song.json otomatis
2. Edit segmen → klik 💾 Simpan atau ⬇ Download
3. Pindahkan ke songs/ → python tools/update_song_index.py

Workflow via Python (akurasi lebih tinggi):
1. python tools/mxl_to_song.py input.mxl songs/nama.json
2. Buka song.json di sini → edit segmen → simpan
3. python tools/validate_song.py songs/nama.json
4. python tools/update_song_index.py → lagu muncul otomatis
