# Song Index Management Workflow

This guide explains how to use the authoring tools to create and manage songs in the MyKey library.

## Quick Start Workflow

### Step 1: Edit Song in Authoring Studio
```
1. Open authoring.html in browser
2. Load or import a song (song.json or .mxl)
3. Edit metadata, segments, and learning structure
4. Click "💾 Save & Index" button
```

### Step 2: Save Files to songs/ Folder
```
1. In the save dialog, navigate to songs/ folder
2. Save the song.json file there
3. The browser will also offer to download index.json
   (or you can skip this, we'll regenerate it)
```

### Step 3: Regenerate index.json

Choose ONE of these methods:

#### **Method A: Windows (Easiest)**
- Double-click `tools/update-index.cmd`
- A window will open, run the scan, then wait for you to press Enter
- Done! index.json is regenerated

#### **Method B: macOS/Linux**
```bash
# One-time setup (add execute permission):
chmod +x tools/update-index.sh

# Then run:
./tools/update-index.sh
```

#### **Method C: Manual Command (All Platforms)**
```bash
# From project root:
python tools/update_song_index.py

# Or specify songs folder:
python tools/update_song_index.py --songs-dir songs/
```

## What Each Tool Does

### `authoring.html`
- **Purpose:** Browser-based editor for song metadata, segments, and learning paths
- **Output:** song.json files + optional index.json preview
- **Use when:** You want to visually edit songs and segments

### `update_song_index.py`
- **Purpose:** Scans songs/ folder and regenerates index.json
- **What it does:**
  - Finds all *.json files in songs/
  - Extracts metadata (title, composer, level, BPM, bar count, segments)
  - Preserves curation fields from existing index.json (listed, collectionId, tags)
  - Writes complete index.json with all entries
- **Use when:** You've added/modified song files and need to update the index

### `update-index.cmd` / `update-index.sh`
- **Purpose:** User-friendly wrapper around update_song_index.py
- **Advantage:** No need to open terminal, just double-click or run
- **Use when:** You prefer graphical/simple interface

## Important Notes

### File Organization
```
songs/
  ├── index.json              ← Auto-generated by update_song_index.py
  ├── collections.json        ← Manual curated file
  ├── 0101 Song Title.json    ← Song files (created by authoring.html)
  ├── 0102 Another Song.json
  └── ...
```

### Curation Fields (Preserved)
When you run `update_song_index.py`, these fields are **preserved from existing index.json**:
- `listed` — Whether song appears in Song Browser (default: true for production songs, false for test_* files)
- `collectionId` — Collection assignment (optional)
- `tags` — Custom tags (optional)

These fields are **regenerated** (overwritten):
- `src` — File path
- `title` — From song.json metadata
- `composer` — From song.json metadata
- `level` — From song.json metadata
- `label` — Formatted display label with BPM, bars, segments, etc.

### Test/Fixture Files
Files matching these patterns default to `listed: false`:
- `test_*.json` (e.g., test_dotted.json)
- `simple_test.json`

You can manually edit these in index.json if needed.

### Error Handling
If a song.json is invalid (missing meta or score), it will be:
- **Skipped** in index regeneration
- **Warning printed** to console
- index.json will still be written with valid songs only

## Troubleshooting

### "No songs found" error
- Check that songs/ folder exists in project root
- Verify at least one *.json file is in songs/
- Ensure the file has valid `meta` and `score` objects

### Changes not showing in app
- After running update script, **refresh the browser** (F5 or Cmd+R)
- Check browser console for CORS errors if using file:// protocol
- Use `python -m http.server 8000` to serve over HTTP instead

### Can't find update-index.cmd on Mac/Linux
- Use update-index.sh instead: `chmod +x tools/update-index.sh && ./tools/update-index.sh`
- Or run Python directly: `python tools/update_song_index.py`

## Advanced: Batch Operations

### Update multiple songs at once
```bash
# Edit all songs in authoring.html, save to songs/ folder
# Then run once:
python tools/update_song_index.py

# This regenerates index.json for ALL songs automatically
```

### Edit curation fields
```bash
# After running update script, you can manually edit songs/index.json:
# - listed: true/false
# - collectionId: "collection_1" or null
# - tags: ["tag1", "tag2"] or []

# Next time you run update script, these fields are preserved
# while other fields refresh from song.json files
```
