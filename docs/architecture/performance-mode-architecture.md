# Performance Mode Architecture

Status: FUTURE  
Priority: HIGH

---

# 1. Purpose

Performance Mode is an immersive fullscreen piano practice environment.

This mode prioritizes:
- notation readability
- minimal distraction
- fullscreen practice
- landscape workflow
- piano stand usability

---

# 2. Philosophy

Performance Mode should feel like:
> a digital music stand

NOT:
> a dashboard interface

---

# 3. UX Goals

Goals:
- maximize notation area
- minimize persistent UI
- reduce cognitive clutter
- support long practice sessions

---

# 4. Planned Features

---

## Fullscreen Notation

Notation should dominate the screen.

---

## Minimal UI

Persistent controls should be minimized.

---

## Floating Overlay Controls

Controls should become:
- temporary
- contextual
- auto-hide capable

---

## Landscape Optimization

Landscape becomes the primary immersive orientation.

---

# 5. Non-Goals

Performance Mode does NOT:
- alter notation semantics
- alter renderer behavior
- alter RuntimeEngine timing

This is purely a presentation mode.

---

# 6. Future Expansion

Potential future ideas:
- piano stand mode
- dark immersive mode
- adaptive overlays
- gesture-only navigation
- practice session presets
